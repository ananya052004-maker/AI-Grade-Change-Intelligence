## What's next (honest punch list, not claimed as done)

1. **AC-7 to a clean ≥15%**: current mechanism is real and measured at ~14.5%; closing the last ~0.5pp needs either a slightly wider execution-quality variance in the simulator or an actual physics-based optimizer (using `trajectory_model.py`'s residual-correction model as the objective) instead of pure case-based retrieval.
2. **SEC-03 RBAC**: no role/session system exists; would need a minimal auth layer even for a local demo.
3. **Remaining 20 edge cases** (§11): several (E-09 reversed transitions, E-10 chained transitions, E-15 confounded transitions) already have data flags (`grade_events.chained`/`confounded`/`REVERSED` outcome) generated by the simulator but no downstream logic reads them yet — the fastest path to closing several of these at once.
4. **A-4 dead-time estimation precision**: works, but calibration is off vs. the PRD's step-input assumption on a smoothstep ramp; would need either a dedicated step-test replay segment or a different estimator.
5. **NFR-3/11 load testing**: not attempted at 500-tag/1Hz scale.
